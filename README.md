# JNT Player

Player de música offline (PWA).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `jnt-player`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` / `(root)` → Save.
4. Aguarde 1–2 min e abra `https://SEU-USUARIO.github.io/jnt-player/` no Chrome do celular.
5. Menu ⋮ → **Instalar app** / **Adicionar à tela inicial**.

Ao atualizar o app, aumente o número em `CACHE` no `service-worker.js` (ex.: `jnt-player-v3`).
